# Changelog

## 1.0.2 (2026-10-30)

- The arena now opens in the Explorer by default. Set `dbzCompanions.position` to `panel` to keep it next to the terminal.
- The Activity Bar icon is now a four-star Dragon Ball, drawn as a plain shape so it shows up in every VS Code theme.

## 1.0.1 (2026-10-28)

- New Marketplace icon: Super Saiyan Goku.

## 1.0.0 (2026-10-28)

First release on the VS Code Marketplace. Earlier versions were private prototypes.

- Goku and Vegeta live in the Dragon Ball Z Arena like VS Code Pets, and level up into Super Saiyan, Super Saiyan 2, Super Saiyan God and Super Saiyan Blue as you code.
- Six arenas: the wasteland, Planet Namek, Kame House, the Tenkaichi Budokai, Kami's Lookout and the wasteland at night. *Change Arena Background* previews each one.
- Scouter HUD, Dragon Balls found by typing, and Shenron's wishes.
- The Hyperbolic Time Chamber focus timer.
- A Marketplace icon, and an Activity Bar icon that shows the fighter's head instead of a solid square.
