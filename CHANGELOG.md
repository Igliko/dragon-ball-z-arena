# Changelog

## 1.0.0 (2026-10-28)

First release on the VS Code Marketplace. Earlier versions were private prototypes.

- Goku and Vegeta live in the DBZ Arena like VS Code Pets, and level up into Super Saiyan, Super Saiyan 2, Super Saiyan God and Super Saiyan Blue as you code.
- Six arenas: the wasteland, Planet Namek, Kame House, the Tenkaichi Budokai, Kami's Lookout and the wasteland at night. *Change Arena Background* previews each one.
- Scouter HUD, Dragon Balls found by typing, and Shenron's wishes.
- The Hyperbolic Time Chamber focus timer.
- A Marketplace icon, and an Activity Bar icon that shows the fighter's head instead of a solid square.
